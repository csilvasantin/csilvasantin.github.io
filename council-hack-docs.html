AdmiraNext Council — Hack Simulation

Documentacion tecnica para el equipo · Actualizado 10 abril 2026

Que es

Una simulacion cinematografica de hackeo que se lanza simultaneamente en los 8 equipos del Consejo de Direccion. Cada maquina muestra contenido unico: escena de pelicula, lenguajes de programacion, grupo hacker, velocidad de scroll y perfil de Terminal distintos.

Como lanzar

Desde la web

Abrir admiranext.html y pulsar el boton HACKEO abajo a la izquierda.

Requiere que el demo server del Mac Mini este activo.

Desde terminal

Funciona desde cualquier maquina con Tailscale (PC, Mac, etc.):

bash launch_remote.sh

Para parar:

bash stop_remote.sh

Requisitos por maquina

Para que el hack funcione en tu Mac:
  • Tailscale instalado y conectado
  • SSH habilitado (Ajustes > General > Compartir > Inicio de sesion remoto)
  • Clave SSH del PC Windows en ~/.ssh/authorized_keys
  • Permisos de Accesibilidad para Terminal (para fullscreen)

Pendientes

Tareas pendientes en el Mac Mini (Gran de Gracia 51):

  • Verificar y reconfigurar Tailscale Funnel para /demo
