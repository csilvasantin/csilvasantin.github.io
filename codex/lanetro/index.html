Piezas

Que hace cada script

Directo

lametric_write.py

Envia texto plano al widget del LaMetric por HTTP y es la via rapida para validar conectividad.

Observacion

lametric_camera_bridge.py

Levanta una web para el movil, usa la camara trasera y sube fotogramas de referencia al Mac.

Demo

lametric_gate_counter.py

Hace secuencias incrementales para mensajes tipo puertas de embarque.

Demo

lametric_sleep_flights.py

Genera mensajes temporales con hora y pais aleatorio para pruebas narrativas.

Frames

lametric_rainbow_text.py

Rasteriza texto en frames RGB `37x8` y sirve como base para futuras animaciones.

Flujo

Como retomarlo rapido

  1. Primero probar escritura directa con un texto corto.
  2. Si hace falta ver el resultado real, arrancar el bridge de camara.
  3. Usar las demos automatizadas solo cuando el canal directo ya responda.
  4. Si se va a evolucionar el proyecto, mover secretos y host a entorno.
python3 tools/lametric_write.py "Hola Admira"
python3 tools/lametric_camera_bridge.py
python3 tools/lametric_gate_counter.py --start-gate 3 --stop-gate 7
python3 tools/lametric_sleep_flights.py --minutes 10
python3 tools/lametric_rainbow_text.py "ADMIRA"

Arquitectura

Control directo y observacion visual

Camino 1

Escritura

Los scripts de control directo envian un `POST` al widget instalado del LaMetric con frames de texto.

Camino 2

Verificacion

El bridge publica una pagina local para movil y guarda la ultima captura en el Mac para inspeccion remota.

Deuda

Falta unificar

No existe aun una CLI `lanetro` ni una configuracion centralizada. Hoy sigue siendo un toolkit operativo disperso.

Proximos pasos

Que haria en la siguiente iteracion

  1. Crear carpeta o repo dedicado `lanetro` con `README` unico.
  2. Sacar `host`, `api_key` y `package` a variables de entorno.
  3. Unificar comandos bajo una CLI corta.
  4. Añadir historial de capturas y una mini galeria web.

Lanetro queda documentado como proyecto operativo y retomable desde cualquier sesion futura.
