Instalacion de Telegram Desktop y Claude Code

Estado verificado

Telegram Desktop reinstalado y Claude Code disponible como binario nativo en Windows. Esta pagina deja el procedimiento visible para repetirlo en cualquier equipo de AdmiraNext.

Resumen operativo

Telegram Desktop

Instalacion oficial para comunicacion y coordinacion diaria.

  • Ruta habitual: %APPDATA%\Telegram Desktop\Telegram.exe
  • Descarga oficial: https://telegram.org/dl/desktop/win64
  • Acceso directo: menu Inicio y escritorio si el instalador lo crea.

Claude Code

CLI nativo para trabajar con Anthropic Claude Code desde terminal.

  • Ruta recomendada: %USERPROFILE%\.local\bin\claude.exe
  • Comprobacion: claude --version
  • El directorio .local\bin debe estar en el PATH de usuario.

Reinstalar Telegram Desktop

  1. Cerrar Telegram si esta abierto.
  2. Ejecutar el desinstalador de Telegram Desktop si existe en %APPDATA%\Telegram Desktop\unins000.exe.
  3. Descargar el instalador oficial desde Telegram.
  4. Ejecutar el instalador y abrir Telegram para iniciar sesion.
Invoke-WebRequest -Uri "https://telegram.org/dl/desktop/win64" -OutFile "$env:TEMP\tsetup-x64.exe"
Start-Process -FilePath "$env:TEMP\tsetup-x64.exe" -Wait
Descargar Telegram

Instalar Claude Code

La instalacion recomendada por Anthropic para Windows usa PowerShell y descarga el instalador oficial.

irm https://claude.ai/install.ps1 | iex

Despues, cerrar y abrir la terminal, y verificar:

claude --version
Documentacion oficial

Si Windows tiene la fecha u hora incorrectas, los certificados HTTPS pueden fallar aunque la URL sea oficial. Antes de reinstalar, conviene activar la sincronizacion automatica de hora en Configuracion de Windows.

Checklist de verificacion

  • Telegram.exe existe dentro de %APPDATA%\Telegram Desktop.
  • claude.exe responde con una version de Claude Code.
  • %USERPROFILE%\.local\bin aparece en el PATH de usuario.
  • La fecha de Windows coincide con la fecha real para evitar errores de certificados.
